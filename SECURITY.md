# Security Policy

## Reporting a vulnerability

**Please don't open a public issue, discussion, or pull request for a security problem.**

Report it privately through GitHub's [private vulnerability reporting](https://github.com/jschlachter/yarp-proxy-manager/security/advisories/new) (Security tab → "Report a vulnerability"). Include the affected component, the version (image tag or commit SHA), and steps to reproduce.

This is a personal project maintained on a best-effort basis. There is no guaranteed response time, but reports are read and fixes are prioritised over feature work.

## Supported versions

Only the latest version on `main` receives fixes.
